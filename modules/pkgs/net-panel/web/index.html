联网架构 …

绿色流动线 = 当前真实走向（读取 ip route get 1.1.1.1、adb、systemd 状态）；紫色 = HK WireGuard 全隧道；橙色 = wg0 的 UDP 封装包经 LAN 网关出去（端点 /32 被 pin 到 LAN）；灰色虚线 = 未启用。

VIVO USB 网络共享 …

打开 = 清除 vivo-off 标记并启动用户服务 gnirehtet-share（含 USB 反向共享 + 18080/1080 代理 + adb reverse）。关闭 = 写入 vivo-off（watchdog 不再自动拉起）并停止服务。

VIVO 热点 …

经 adb 执行 cmd wifi start-softap / stop-softap（Android 11+）；密码从配置里的 pass_file 读入、经 stdin 传给手机，不显示不记录。不支持时自动在手机上打开热点设置页。

HK WireGuard …

调用 Home Manager 里现成的 isvoro-wg-up / isvoro-wg-down（内部用 sudo）。全隧道：开启后本机及经本机代理的手机流量都从香港出。

  


  

    
反向代理（给手机用）

    

    

    
SOCKS5 适用：iPhone 的 Surge / Shadowrocket（规则 FINAL→SOCKS5，Wi-Fi 代理保持关闭）、邮件 IMAP/SMTP、X(Twitter)、Telegram 等任意 TCP App；命令行 curl --socks5-hostname、git、ssh ProxyCommand。

    

    

    
HTTP 适用：iPhone Wi-Fi「配置代理 → 手动」后的 Safari、App Store 及遵守系统 HTTP 代理的 App；安卓/电脑的 http_proxy/https_proxy（npm、pip、apt）。只放行 CONNECT 443/563，Mail、X 这类不走系统代理的 App 请用 SOCKS5。
