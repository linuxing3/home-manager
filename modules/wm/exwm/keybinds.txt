EXWM (Emacs X Window Manager) — Super is Mod4 (s-)

  Super+Return          terminal (st)
  Super+D               dmenu_run -l 10
  Super+G               brave
  Super+E               st -t hx -e hx
  Super+Shift+N         nnn
  Super+Q               kill buffer / close X window
  Super+W               exwm-workspace-switch
  Super+I               toggle line-mode / char-mode
  Super+R               run shell command
  Super+0..9            switch / create workspace
  Control+q             send next key to X window directly

Pick EXWM in greetd (F3) / LightDM, or run exwm-nested / exwm-session.
