# Quick Commands

## Remote bootstrap

```bash
nix run github:linuxing3/home-manager/aarch64#bootstrap
```

## Local validate and switch

```bash
./skills/hm-bootstrap/scripts/validate.sh
./skills/hm-bootstrap/scripts/switch-local.sh
```

## Fix sensitive folder permissions

```bash
./skills/hm-bootstrap/scripts/harden-perms.sh
```
